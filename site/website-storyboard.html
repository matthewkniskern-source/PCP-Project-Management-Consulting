Design rationale and implementation boundary

Consistent public navigation

Shared navigation and service-detail links make PCP's major offerings discoverable without requiring visitors to search through long pages.

Clear audience separation

The marketing website serves prospects and clients; a separate portal entry demonstrates staff-oriented record and workflow interactions.

Responsive layout planning

Page sections and cards reorganize at narrower widths while retaining the same page hierarchy and accessibility-oriented navigation.

Production security is separate

The current portal has no actual Entra authentication, MFA, protected database or server-side authorization. Those future-state controls are explained in the network architecture documentation.

Academic prototype: This storyboard visualizes the delivered public website and employee demonstration. The simulated Entra transition and client-side role controls are presentation features only. No real client data, credentials, or protected production backend are present.
